Luma Privacy Policy

Last updated: 2026-08-24

Luma is published by OGSpiderX (github.com/ogspiderx).

THE SHORT VERSION

Luma does not collect, store, or transmit any personal data. There is no
account, no telemetry, no analytics, and no data sent to OGSpiderX or anyone
else. Everything Luma knows about what you have downloaded stays on your own
computer, in files you can open, move, or delete at any time.

WHAT LUMA STORES, AND WHERE

Luma keeps a small amount of information so it can work the way you have set
it up. All of it lives on your own machine:

Your settings, such as where downloads are saved and how many run at once.
A list of what you have downloaded: title, link, size, quality, and when.
A list of anything that did not work, and why, in plain language.
A log of anything that crashed, used only to fix problems if you report one.

If you installed Luma with the setup wizard, these live in your Windows user
profile, under AppData\Local\Luma. If you are running the portable version,
they live in the same folder as the application itself. Either way, deleting
that folder removes everything Luma has ever recorded.

WHAT LUMA SENDS OVER THE INTERNET

Luma is a downloader, so it does talk to the internet, but only for the job
in front of it:

It contacts the video site to fetch whatever link you gave it.
The first time it runs, it downloads the small set of tools it needs to do
that, from their own official sources.
It briefly measures your connection speed against a public test endpoint, so
it can decide how many downloads to run at once. No result of that test is
sent anywhere; it is only used to set a number locally.

Nothing else is contacted. No usage statistics, crash reports, or update
checks are sent automatically, and Luma does not check in with OGSpiderX at
all.

WHAT LUMA DOES NOT DO

Luma does not require or create an account.
Luma does not use cookies, trackers, or advertising identifiers.
Luma does not read, scan, or transmit any other files on your computer.
Luma does not share anything with a third party, because nothing is
collected in the first place.

CHILDREN

Luma is a general-purpose tool with no age gate, no account, and no data
collection, so there is nothing here that specifically concerns a child's
privacy beyond what applies to any user.

CHANGES TO THIS POLICY

If this policy ever changes, the updated version will be published alongside
the application, with a new date at the top of this document.
